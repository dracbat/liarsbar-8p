[size=5][b]Liar's Bar — 8 Player Mod[/b][/size]

Raises Liar's Bar from 4 players to 8.

Built with BepInEx 6 (IL2CPP) and Harmony. [b]No game files are modified on disk[/b] — everything is patched while the game runs, and Steam's [i]Verify integrity of game files[/i] removes it completely.

[line]

[size=4][b]Read this first[/b][/size]

[b]Everyone playing together must install this and run the same version.[/b] A player without the mod, or on a different version, will desync the lobby. The version you are running is drawn in the top-left corner in game, and every player is warned automatically if someone's build differs.

[line]

[size=4][b]What it does[/b][/size]

[list]
[*][b]Lobbies of up to 8.[/b] Steam's own lobby limit, Mirror's connection cap and the Steam transport's separate cap are all raised — three different limits, all of which had to move.
[*][b]A table that stays a table.[/b] Seats are re-spaced evenly around the bar for however many are actually playing, so five, six or seven sit properly rather than bunching along one side. Empty chairs are hidden.
[*][b]Everyone gets dealt.[/b] The deal is rebuilt to hand cards to every seat — 5 players get 25 cards, 8 get 40, in the same Ace/King/Queen/Joker proportions the game ships with, so the bluffing odds feel like vanilla.
[*][b]Turn order that visits every seat[/b], including the ones that did not exist before.
[*][b]Lobby podiums and name plates for 8[/b], arranged in two rows with the camera pulled back so everyone is in frame and every name sits above its own player.
[*][b]Whose turn it is[/b], shown clearly for every player.
[/list]

[b]At four players or fewer, the game behaves exactly as it shipped.[/b] The mod is for playing with more people, not for changing the game you already have.

[line]

[size=4][b]What has actually been tested[/b][/size]

Every row here is a real table of that many separate game clients, with the seating measured on [i]every[/i] machine rather than only the host's.

[list]
[*][b]Liar's Deck — Basic[/b]: 5, 6, 7 and 8. Everyone seated, dealt, taking turns.
[*][b]Liar's Deck — Devil[/b]: 5, 6, 7 and 8, with the devil's deal seen to trigger.
[*][b]Chaos Deck[/b]: 5, 6, 7 and 8, with a chaos card thrown and resolved at every size.
[*][b]Liar's Dice[/b]: seated and playing at 5, 6, 7 and 8.
[*][b]Liar's Texas[/b]: eight players seated, dealt and taking turns.
[*][b]Liar's Poker[/b]: five players seated, dealt and taking turns.
[/list]

[b]And played for real:[/b] a full session of Liar's Deck by five people on five different PCs over Steam, run to a winner, with no errors from the mod on any machine.

[b]Known limits, stated plainly:[/b]
[list]
[*][b]Eight people on eight machines has never been done.[/b] Eight [i]connections[/i] have been proven many times over; eight actual people in a Steam lobby has not. Treat your first eight-player game as the test that it is.
[*][b]Liar's Spin[/b] has not been started from the test rig, so it is untested — not known broken, just unproven.
[*][b]Liar's Dice[/b]'s turn order is confirmed at 5 and 6 and unresolved at 7 and 8.
[*][b]The Chaos deck[/b] makes clients log a harmless-looking error handling two of the game's own networked calls. That is the base game, not this mod — [b]the identical errors happen at four players with no mod installed[/b]. The mod now survives them instead of letting them end the session.
[/list]

[line]

[size=4][b]How this was made[/b][/size]

[b]This mod was written by an AI[/b] — Claude, working from the game's decompiled code and directed by one person over a few days. It started as a for-fun experiment in how far that could be taken, and it is shared in that spirit rather than as a commercial product.

That is a reason to read the limits above. It is not a reason to expect something flaky. Nothing here shipped on the strength of "it should work" — every fix was checked by running the game and reading what it actually did, and the whole thing has been played end to end by real people. Where something is untested, this page says so instead of rounding it up.

[size=4][b]Installation[/b][/size]

[list=1]
[*]Download [b]Install-LiarsBar8P.bat[/b] from the Files tab.
[*]Run it. It finds Liar's Bar through Steam automatically, removes any previous copy of the mod, and installs the current one.
[*]It asks for administrator permission because the game lives under Program Files.
[*][b]The first launch after installing is slow[/b] — up to a few minutes while BepInEx prepares the game. This happens once. Let it reach the main menu.
[/list]

[b]Keep that file — running it again is how you update.[/b] It checks for the newest release every time it runs, so it never goes stale.

It is a plain text file. Open it in Notepad first if you would rather see what it does before running it.

[spoiler=Manual install instead]Download the zip from the Files tab, extract it, and run install.bat from inside the extracted folder. Or entirely by hand: copy the zip's contents into your Liar's Bar folder so that winhttp.dll and BepInEx/ sit next to "Liar's Bar.exe".[/spoiler]

To confirm it worked, look at the top-left corner in game.

[line]

[size=4][b]Uninstalling[/b][/size]

Run [b]uninstall.bat[/b] from the zip, or delete winhttp.dll, doorstop_config.ini, .doorstop_version, changelog.txt and the BepInEx/ and dotnet/ folders.

Because no game files are ever modified, Steam's [b]Verify integrity of game files[/b] also restores everything.

[size=4][b]Testers wanted[/b][/size]

The one thing this mod cannot test on its own is a full lobby of people on their own PCs. If you play a game with it — five, six, seven or eight — a log is genuinely useful, whether it went well or badly.

Especially wanted:
[list]
[*][b]Eight players.[/b] Nobody has done it outside a test rig.
[*][b]Modes other than Liar's Deck.[/b]
[*][b]Any bar other than the one you usually play in.[/b] There are four, and the mod has only ever been watched in one.
[*][b]Anything that looks wrong[/b] — a player in the wrong seat, a hand that never arrives, a name plate out of place, a round that stops.
[/list]

[b]Sending a log[/b]

There is one file, and [b]it is overwritten every time the game starts[/b], so copy it out before launching again.

[list=1]
[*]Play the game, then quit to the desktop.
[*]In Steam, right-click [b]Liar's Bar → Manage → Browse local files[/b].
[*]Copy [b]BepInEx\LogOutput.log[/b] somewhere safe.
[*]Post it here, or open an issue at [url=https://github.com/dracbat/liarsbar-8p/issues]github.com/dracbat/liarsbar-8p/issues[/url].
[/list]

Please say [b]how many players[/b], [b]which mode[/b], and [b]what looked wrong[/b]. The host's log is the most useful, but any player's log helps.

[quote][b]Have a look at it before you post it.[/b] The log records the Steam names of everyone in your lobby, because that is what the game calls them. There are no passwords, keys or addresses in it — but your friends' names are, so treat it like a screenshot of your friends list.[/quote]
