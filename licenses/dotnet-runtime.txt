.NET Runtime 6.0.7 (Windows x64) - LICENCE INFORMATION
==============================================================================

This file covers the dotnet/ folder of this download. That folder holds the
Microsoft .NET runtime (Microsoft.NETCore.App) version 6.0.7, built from
https://github.com/dotnet/runtime at tag v6.0.7 (commit
0ec02c8c96e2eda06dc5b5edfdbdba0f36415082), plus seven Microsoft library DLLs
that BepInEx ships alongside it. All of it is Microsoft's work, redistributed
unmodified as part of BepInEx.

WHICH FILES ARE UNDER WHICH LICENCE
------------------------------------------------------------------------------

1. Microsoft.DiaSymReader.Native.amd64.dll - NOT INCLUDED in this download.
   BepInEx's own download carries this file, which is under the Microsoft
   .NET Library License rather than MIT. All it does is add source line
   numbers to .NET stack traces; BepInEx and the mod run without it, and that
   licence's conditions for passing the file on cannot be met by including a
   text file. So this download leaves it out, and is otherwise BepInEx's
   dotnet/ folder unchanged.

2. Microsoft.Bcl.AsyncInterfaces.dll
   Microsoft.Extensions.DependencyInjection.dll
   Microsoft.Extensions.DependencyInjection.Abstractions.dll
   Microsoft.Extensions.Logging.dll
   Microsoft.Extensions.Logging.Abstractions.dll
   Microsoft.Extensions.Options.dll
   Microsoft.Extensions.Primitives.dll
   Licence: MIT (section A), with the third-party notices in section D.
   These are not part of the runtime. Each is identical to the copy in
   Microsoft's NuGet package of the same name, version 6.0.0 (built from
   dotnet/runtime at tag v6.0.0), which Microsoft publishes under the MIT
   License with the same LICENSE.TXT as section A.

3. Every other file in dotnet/: 176 DLLs (including coreclr.dll, clrjit.dll,
   hostpolicy.dll, msquic.dll and all System.*.dll), plus
   Microsoft.NETCore.App.deps.json, Microsoft.NETCore.App.runtimeconfig.json
   and the .version stamp.
   Licence: MIT (section A), with the third-party notices in section D.
   The DLLs and .json files are identical to those in Microsoft's runtime
   pack Microsoft.NETCore.App.Runtime.win-x64 6.0.7, which Microsoft
   publishes under the MIT License together with the LICENSE.TXT in section A
   and the THIRD-PARTY-NOTICES.TXT in section D.

   Please note: Microsoft's current licence information for .NET on Windows,
   https://github.com/dotnet/core/blob/main/license-information-windows.md
   (revised November 2024), lists coreclr.dll under the .NET Library License
   (section C), and
   https://github.com/dotnet/core/blob/main/license-information.md
   (revised December 2024) says Windows runtime packs use the .NET Library
   License. Microsoft describes both pages as informative only and not a
   licence. The 6.0.7 runtime pack itself declares the MIT License, and when
   6.0.7 was released (July 2022) Microsoft's Windows licence information did
   not list coreclr.dll as an exception to MIT. To the extent the .NET Library
   License applies to coreclr.dll, the terms in section C apply to it.

Sections A, C and D below reproduce the licence texts. Each was copied from
the source named in its heading. A and D are byte-for-byte copies. C is shown
as the text of the web page without its HTML markup, one paragraph per line.
