.NET RUNTIME
------------------------------------------------------------------------------

The dotnet/ folder is the Microsoft .NET runtime 6.0.7 for Windows x64
(Microsoft.NETCore.App), redistributed by BepInEx so that the loader can run
inside an IL2CPP game. BepInEx also puts seven Microsoft library DLLs in it,
from their version 6.0.0 NuGet packages: Microsoft.Bcl.AsyncInterfaces.dll
and Microsoft.Extensions.*.dll.

  https://github.com/dotnet/runtime  (tag v6.0.7)
  Copyright (c) .NET Foundation and Contributors
  Copyright (c) Microsoft Corporation

  The folder is MIT licensed, and the runtime's own third-party notices apply
  to it. Microsoft's current licence information for .NET on Windows lists
  dotnet/coreclr.dll under the Microsoft .NET Library License instead; the
  6.0.7 runtime package itself declares MIT. See:
  https://github.com/dotnet/core/blob/main/license-information-windows.md
  Licence texts and the runtime's third-party notices:
  licenses/dotnet-runtime.txt

  Left out: BepInEx's own download also carries
  dotnet/Microsoft.DiaSymReader.Native.amd64.dll, which is under the Microsoft
  .NET Library License. Its only job is adding line numbers to .NET stack
  traces, the loader and the mod run without it, and that licence's
  conditions for passing it on cannot be met by including a text file - so
  it is not in this download.

GETTING THE SOURCE
------------------------------------------------------------------------------

The LGPL components above are redistributed unmodified. Their complete
corresponding source can be obtained from the project pages listed for each:

  BepInEx        6.0.0-be.697, commit 53625800b86f6c68751445248260edf0b27a71c2
  UnityDoorstop  4.3.0, tag v4.3.0
  Il2CppInterop  1.4.6-ci.426, a build of the project's master branch

If you would rather have it from us: open an issue at
https://github.com/dracbat/liarsbar-8p/issues and we will provide source
archives for the versions above. For BepInEx and UnityDoorstop those are the
exact commits named. For Il2CppInterop the exact commit that build 1.4.6-ci.426
came from is not recorded anywhere we have found - it is a master build from
after the 1.4.6 version bump (commit 975e421e, June 2023) - so we would provide
the closest source we can identify, and say exactly what it is.

If anything in this file is wrong or incomplete, please say so on the issue
tracker - it will be corrected.
